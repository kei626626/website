01

今日やること

1. Sunoって何？

AIでボーカル付きの楽曲を生成できるサービス。

2. BGMの重要性

音楽が映像の印象・感情・テンポを大きく左右する。

3. 同じ歌詞で比較

同じ歌詞を使って、複数ジャンルの曲を聴き比べる。

4. 音楽の表現

AIは作業短縮だけでなく、表現の幅を広げるツール。

02

Sunoって何？

歌詞や曲調の指示から、AIが楽曲を生成してくれるサービス。

  • 歌詞から曲を作れる
  • ジャンル指定ができる
  • ボーカル付きで生成できる
  • 数十秒〜数分で試作できる

使えそうな場面

動画BGM / SNS動画 / 仮歌 / イベントOP / ネタ曲 / MV制作 / アニメOP風デモ

SAMPLE 01

深夜アニメOP風

印象

普通にアニメ主題歌っぽい

エモ青春夜疾走感

比較の基準になる“正解版”。

1分〜1分30秒程度の長さ。 1980年代の日本のシティポップや、昭和レトロなポップスを感じる、懐かしくエモーショナルな楽曲。 深夜の東京、ネオン街、雨上がりの道路、古い駅、静かなコンビニ、カセットテープのようなノスタルジックな空気感をイメージする。 切なさと温かさを同時に感じる、大人っぽくおしゃれな雰囲気。 終電後の街をゆっくり走る車の中で聴こえるような、夜景に合うサウンドにする。 レトロシンセ、温かいエレピ、ファンキーなベースライン、クリーンギター、柔らかいドラムマシン、きらめくパッド、アナログ感のある音色を使用。 サビは懐かしく印象的で、1980年代アニメのエンディングテーマのような余韻を出す。 女性ボーカル。 柔らかく、少し息混じりで、感情的な歌声。 イントロは短め。 最初の10秒以内に歌が始まる。 キーワード： シティポップ、昭和レトロ、東京の夜、ネオン、夜景、雨、ドライブ、カセットテープ、ノスタルジック、アニメED、都会的。

SAMPLE 02

演歌 / 昭和歌謡風

印象

急に人生が重くなる

哀愁ネオン深夜昭和

同じ歌詞なのに、一気に“夜のドラマ”になるギャップ枠。

1分〜1分30秒程度の長さ。 昭和の演歌やムード歌謡を感じる、哀愁たっぷりの日本的な楽曲。 終電後の東京、雨に濡れたネオン街、無人の駅、光る看板、疲れた心がひとりで夜を歩いているような世界観。 孤独感、懐かしさ、切なさ、静かな希望を強く感じる雰囲気にする。 演歌特有のこぶし、情感の強い歌唱、ゆったりしたテンポ、ドラマチックなメロディを入れる。 演奏には、演歌風ギター、ピアノ、ストリングス、柔らかいシンセ、深いリバーブを使用。 昭和の深夜ドラマのエンディングテーマのような、レトロで映画的な雰囲気。 女性ボーカル。 大人っぽく、感情たっぷりで、少しハスキーな歌声。 イントロは短め。 最初の10秒以内に歌が始まる。 キーワード： 演歌、昭和歌謡、ムード歌謡、深夜、終電、東京、ネオン、雨、孤独、哀愁、夜景、感情的、日本的、レトロ。

SAMPLE 03

ホラー / ダークアンビエント風

印象

テックまが怖い

不穏ノイズ違和感深夜駅

音が変わるだけで、同じ世界が“怖い作品”に変わる。

1分〜1分30秒程度の長さ。 心理ホラーアニメや、深夜の都市伝説作品のような、不穏で不気味なダークアンビエント楽曲。 終電後の無人駅、点滅するネオン、遠くで響く電車の音、冷たい雨、静まり返ったホームをイメージする。 小さなマスコットキャラクターが、少しずつ不気味で怖い存在に見えてくるような違和感を出す。 孤独感、不安感、夢の中にいるような感覚、現実が歪むような不気味さを演出する。 低音ドローン、歪んだシンセ、逆再生音、グリッチノイズ、重いサブベース、不気味なパッド、金属的な残響、VHSノイズ、最小限の打楽器を使用。 Aメロは静かで不穏。 サビでは世界が崩れるように、より強い緊張感と不気味さを出す。 女性ボーカル。 囁くようで、遠くから聞こえる夢の中の声のような歌声。 イントロは短く、不穏に。 最初の10秒以内に歌が始まる。 キーワード： 心理ホラー、深夜の東京、無人駅、ネオン、雨、都市伝説、グリッチ、VHSノイズ、不気味、違和感、ダークアンビエント。

AI NOTE / 制作のひきだし

【GitHubへのアップロード】
1. ZIPを展開してください。
2. GitHubの kei626626/website で「Add file → Upload files」を開きます。
3. ai-note フォルダごとドラッグし、変更をコミットします。
   最終的に ai-note/index.html という配置になればOKです。
4. GitHub Pagesの公開完了後、既存の公開サイトURLの末尾に ai-note/ を付けて開き、ブックマークします。
   標準の公開先なら https://kei626626.github.io/website/ai-note/ です。
   カスタムドメインや公開フォルダが設定されている場合は、その公開先に合わせてください。

【シートからの自動読み込み】
指定済みの「週報AI」のシート1（gid=0）、A:Hを読み込みます。
掲載日／分野／ツール名／変わったこと／実務への影響／試す価値・試し方／提供条件・制約／出典URL
見出しは1行目、内容は2行目以降にしてください。
土曜の週報がシートに追記されれば、ページを次に開いたとき・再読み込みしたときに反映されます。
ページを開いたままの定期ポーリングはありません。

【重要：読み込みに必要な公開範囲】
このHTMLはGoogleへのログイン認証を持たない静的ページです。
非公開のシートは読み込めません。接続失敗時には案内を表示し、実データとデモを混同しません。
シートを公開してよい場合に限り、シートの「共有」で「一般的なアクセス」を「リンクを知っている全員・閲覧者」にしてください。
この設定は自動では変更していません。
公開するとリンクを知る人がシートを閲覧でき、HTMLにもシートIDが入ります。社内情報・個人情報を含むシートには使わないでください。
現時点で公開したくない場合は設定を変えず、別の公開用シートや認証付きの仕組みに切り替える相談をしてください。
Google側の制限で読み込めない場合は設定が正しくてもエラーになります。その際はエラー表示のままにし、別の接続方式を検討してください。

【ページの機能】
最新メモのピックアップ／分野別フィルター／キーワード検索／掲載日フィルター／あとで見る
「あとで見る」はその端末・ブラウザのローカル保存です。PCとスマホで同期しません。
X動画は埋め込まず、元投稿を新しいタブで開きます。
ページは閲覧専用。シートを編集・削除する機能や認証キーはありません。
